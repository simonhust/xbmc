# DTDL Blu-ray Seek 孤儿帧 Filter 实现计划

## 背景与问题

暴力史 UHD 原盘（单主文件 `00005.m2ts`，BL PID 0x1011 + EL PID 0x1015，均有 EP_map）seek 后画面卡住。

**根因分析（已确认）：**
- BL 与 EL 的 EP_map 粗粒度 PTS 完全对齐（102, 103, 104...）
- 但 BL 与 EL 的 **SPN 差距巨大**：最大差 679,908 个 TS 包 ≈ 130MB ≈ 20 秒数据
- libbluray 的 `min(bl_spn, el_spn)` seek patch 把 seek 位置改到 EL 的 SPN
- EL SPN 位置**不是 BL 的有效访问点（I 帧）**，BL 解码器等不到 I 帧 → 卡画面
- 产生的孤儿帧：DTS 早于 seek 目标时间、没有对应 BL/EL 配对帧的包

## 解决方案

在 codec 单序列配对路径加 **seek-time filter**：DTS 早于 seek 目标时间的包（孤儿帧）直接跳过，其余包正常入队配对。

单序列配对本身支持 EL 先到场景（EL 入队等待 BL 到达后配对），filter 不破坏该能力。

### Filter 生效条件
1. **单 clip**（`!isMultiClip`）— 多 clip 有 PTS 回绕，不适用
2. **`m_seekTime >= 1s`** — seekTime < 1s 时 filter 不生效（起始播放场景）
3. **`packet.dts < m_seekTime`** → 跳过该包
4. `dts < 0` 自动置 0

### 应用位置
仅单序列配对路径（`isNoElEpMap = false` 的 `else` 分支，即 Blu-ray 有 EP_map 场景）。双序列配对路径（`DualLayerAccumulate`）不加。

## 代码改动（已就位，未提交）

### 1. `xbmc/cores/VideoPlayer/Interface/DemuxPacket.h`
- 新增字段 `double m_seekTime;`（默认 `DVD_NOPTS_VALUE`）
- 构造函数初始化

### 2. `xbmc/cores/VideoPlayer/DVDDemuxers/DVDDemuxFFmpeg.h`
- 新增成员 `double m_dv_seek_time = DVD_NOPTS_VALUE;`

### 3. `xbmc/cores/VideoPlayer/DVDDemuxers/DVDDemuxFFmpeg.cpp`
- `SeekTime()` 中记录 `m_dv_seek_time = time * DVD_TIME_BASE / 1000.0;`
- `ReadInternal()` 中 `pPacket->m_seekTime = m_dv_seek_time;`（video 包）

### 4. `xbmc/cores/VideoPlayer/DVDCodecs/Video/DVDVideoCodecAmlogic.cpp`
- `AddData()` 单序列配对路径（`else` 分支，line ~708）加 filter：
```cpp
if (!packet.isMultiClip && packet.m_seekTime >= DVD_TIME_BASE * 1.0 &&
    packet.dts != DVD_NOPTS_VALUE)
{
    double dts_val = packet.dts;
    if (dts_val < 0)
        dts_val = 0;
    if (dts_val < packet.m_seekTime)
    {
        // skip orphan packet
        return true;
    }
}
```

## 验证

1. 编译（`cmake --build` 或 CoreELEC 构建）
2. 用暴力史 UHD 原盘（需 AACS 密钥）实际播放：
   - 从头播放正常
   - 随机 seek 多个位置（10 次），观察：
     - 画面不再卡住
     - 无孤儿帧（BL/EL 配对正常）
     - kodi.log 中出现 `skip orphan packet` 日志（DEBUG 级别）
3. 回归测试：
   - 多 clip 圆盘：filter 不生效（`isMultiClip = true`）
   - seekTime < 1s：filter 不生效
   - 非圆盘 M2TS（isNoElEpMap = true）：走双序列路径，不受影响
