# Plan: HDR PGS Subtitle Rendering (amvecm LUT + GPU Shader)

## 最终方案

利用 amvecm OSD1 硬件 LUT 处理 HDR PGS 字幕，GPU Shader 处理 GUI，实现独立控制。

---

## 架构

```
┌─────────────────────────────────────────────────────────────┐
│  HDR 视频播放                                                │
│                                                             │
│  Video Plane (PQ) ──→ 直接输出                               │
│                                                             │
│  OSD1 Plane:                                                │
│  ├── Subtitles (sRGB) ──→ amvecm LUT ──→ PQ               │
│  │                      (EOTF + OETF, 零 GPU 开销)          │
│  │                                                          │
│  └── GUI (sRGB) ──→ GPU Shader ──→ PQ                     │
│                    (独立亮度/饱和度控制)                      │
└─────────────────────────────────────────────────────────────┘
```

## 实现步骤

### Step 1: DVDOverlayImage.h — 添加 HDR 标记

```cpp
// 在 CDVDOverlayImage 类中添加
bool m_isHdrPq{false};
```

### Step 2: DVDOverlayCodecFFmpeg.cpp — 检测 HDR PGS

```cpp
bool PgsIsPqAuthored(const CDVDStreamInfo& hints)
{
  switch (hints.hdrType)
  {
    case StreamHdrType::HDR_TYPE_HDR10:
    case StreamHdrType::HDR_TYPE_HDR10PLUS:
    case StreamHdrType::HDR_TYPE_DOLBYVISION:
      return true;
    default:
      return false;
  }
}

// 在 Open() 中
m_pgsIsPqAuthored = PgsIsPqAuthored(hints);

// 在 GetOverlay() 中
overlay->m_isHdrPq = m_pgsIsPqAuthored;
```

### Step 3: WinSystemAmlogic.cpp — amvecm LUT 管理

```cpp
class CAMLOSD1LUT {
public:
    static bool ApplySDR2PQ(float sdrPeakNits);
    static bool Clear();
    
private:
    static bool WriteSysfs(const char* path, const unsigned int* values, int count);
    static bool WriteSysfsInt(const char* path, int value);

```

### Step 4: amvecm LUT 写入

```cpp
bool CAMLOSD1LUT::ApplySDR2PQ(float sdrPeakNits) {
    // 1. 写入 EOTF LUT (sRGB→linear)
    WriteSysfs("/sys/module/amvecm/parameters/osd_eotf_r_mapping", eotf_709_100);
    WriteSysfs("/sys/module/amvecm/parameters/osd_eotf_g_mapping", eotf_709_100);
    WriteSysfs("/sys/module/amvecm/parameters/osd_eotf_b_mapping", eotf_709_100);
    
    // 2. 写入 OETF LUT (linear→PQ)
    WriteSysfs("/sys/module/amvecm/parameters/osd_oetf_r_mapping", oetf_2084);
    WriteSysfs("/sys/module/amvecm/parameters/osd_oetf_g_mapping", oetf_2084);
    WriteSysfs("/sys/module/amvecm/parameters/osd_oetf_b_mapping", oetf_2084);
    
    // 3. 触发 VSYNC 同步 reload
    WriteSysfsInt("/sys/module/amvecm/parameters/reload_lut", 1);
    
    return true;
}
```

### Step 5: OverlayRendererGLES.cpp — Shader 选择

```cpp
ShaderMethodGLES GetOverlayTextureShaderMethod(bool isHdrPqAuthored)
{
  if (!isHdrPqAuthored) return ShaderMethodGLES::SM_TEXTURE_NOBLEND;
  
  return CServiceBroker::GetWinSystem()->GetGfxContext().IsTransferPQ()
             ? ShaderMethodGLES::SM_TEXTURE_NOBLEND_HDR_PGS_PQ_OUTPUT
             : ShaderMethodGLES::SM_TEXTURE_NOBLEND;
}
```

### Step 6: RenderSystemGLES.cpp — 添加 Shader 变体

```cpp
// 在 InitialiseShaders() 中
definesHdrPgsPqOutput += "#define KODI_HDR_PGS_PQ_OUTPUT 1\n";

shaderSlot(ShaderMethodGLES::SM_TEXTURE_NOBLEND_HDR_PGS_PQ_OUTPUT) =
    std::make_unique<CGLESShader>("gles_shader_texture_noblend.frag", definesHdrPgsPqOutput);
```

### Step 7: gles_shader_texture_noblend.frag — Shader 逻辑

```glsl
#ifdef KODI_HDR_PGS_PQ_OUTPUT
  // HDR PGS: amvecm 已处理 pow()，这里只做简单调整
  if (abs(m_hdrPgsPeak - 1.0) > 0.0001 || abs(m_hdrPgsSaturation - 1.0) > 0.0001) {
    // 需要调整亮度/饱和度
    rgb.rgb = convertHdrPgsForPqOutput(rgb.rgb);
  }
  // 否则直接输出 (amvecm LUT 已完成转换)
#endif
```
